# 🧶 Tejedora y Punto

**Autora:** Tabatha ([@tbtha](https://github.com/tbtha))  
**Proyecto:** Plataforma web artesanal con narrativa editorial y lógica funcional clara.
---

## 🌐 Contexto del desarrollo

**Tejedora y Punto** es una aplicación web desarrollada desde cero, que integra catálogo de productos textiles, narrativa y gestión de contenidos. El proyecto busca conectar lo artesanal con lo digital, utilizando una arquitectura modular, validaciones personalizadas y una estética coherente con la identidad del oficio.

El desarrollo se orienta a la escalabilidad, la claridad funcional y la calidez visual, permitiendo que cada componente (producto, formulario, entrada editorial) refleje propósito y sentido.

---

## ⚙️ Requerimientos del sistema

### ✅ Requerimientos funcionales

- Visualización de productos con imagen, descripción y precio.
- Registro e inicio de sesión de usuarios.
- Gestión de carrito de compras.
- Publicación y edición de entradas de blog.
- Panel de administración para productos e imágenes.
- Validación de formularios con mensajes editoriales.

### 🛡️ Requerimientos no funcionales

- Accesibilidad desde dispositivos móviles.
- Seguridad básica mediante validación de roles y logs de actividad.
- Modularidad del código para facilitar mantenimiento.

---

## 🛠️ Herramientas y decisiones técnicas

- **HTML semántico**: estructura clara y accesible.
- **CSS modular**: estilos coherentes con la identidad visual del proyecto.
- **JavaScript**: validaciones, lógica de roles, interacción dinámica.
- **Validaciones personalizadas**: mensajes editoriales y control de errores.
- **Arquitectura modular**: funciones reutilizables, componentes escalables.
- **GitHub**: control de versiones, documentación y despliegue.
- **Narrativa editorial**: integración de textos con propósito en cada sección.

---


## 🎯 Conclusión

Este proyecto no solo resuelve necesidades funcionales, sino que transmite una visión: integrar lo artesanal y lo digital con coherencia, sensibilidad y propósito.  
**Tejedora y Punto** es una plataforma que respeta la lógica del oficio, la estética del territorio y la experiencia del usuario, desde el código hasta el relato.
